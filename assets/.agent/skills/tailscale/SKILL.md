# Tailscale

Choose the guide for the job:

- [Private HTML pages](html-private-pages/SKILL.md): Save a self-contained HTML plan, report, or explanation under `AgentPages/<project>/` and return a verified link.
- [App Serve](tailscale-app-serve/SKILL.md): Expose an existing local web app through Tailscale Serve without publishing it to the internet.

For both, inspect the current node and Serve configuration before making changes. Keep unrelated routes and Funnel settings untouched.
