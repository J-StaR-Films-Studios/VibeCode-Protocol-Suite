## Spec
**Confirmed blocker, WARNING, high confidence:** `src/takomi-stats.js:406-421` and the runtime mirror attribute tool-result usage to the last selected model, even though Pi 0.99.1's `ToolResultMessage` has usage but no provider or model. This conflicts with BLD-002's requirement to "preserve native per-kind/source/model attribution where recorded; mark missing provenance or usage plainly rather than inferring provider costs." A tool's tokens can therefore enter the wrong model bucket and receive that model's estimated price. Keep those tokens, but mark their model attribution unknown in both scanners.

The inspector includes tool-result tokens but not their cost. Whether it should use the persisted native cost needs an explicit decision; I would not infer a model price. This is separate from BLD-003's broader pricing-completeness work.
